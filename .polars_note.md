Tips Performa
Gunakan scan_* (lazy) daripada read_* (eager) untuk dataset besar
Gunakan format Parquet, bukan CSV, kalau bisa — jauh lebih cepat dan hemat ruang
Hindari .apply() dengan fungsi Python murni — pakai expression native Polars, jauh lebih cepat karena tereksekusi paralel di Rust
Chain banyak operasi dalam satu lazy query supaya optimizer bisa bekerja maksimal
