# Titanic Survival Analysis & Predictive Modeling

## Executive Summary

An end-to-end analytical and machine learning project
investigating the factors associated with passenger survival
and developing a predictive classification model.

## Business Questions

- What factors are associated with survival?
- How do passenger demographics affect survival?
- How does passenger class affect survival?
- Can survival be predicted reliably?
